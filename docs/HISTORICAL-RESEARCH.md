# Historical research / 历史研究

The sibling study documents record local experiments, including failed candidates and earlier acceptance mistakes. Paths under `output/`, references to old demo commands, and earlier example folders describe that historical workspace; they are not promised downloads or runnable entry points in this curated release. The local files were preserved, but are excluded from the public Git tree.

这些研究文档保留本地试验结果、失败候选和早期验收遗漏。文中的 `output/`、旧 demo 命令与旧示例目录属于历史工作区记录，不表示精选发布包含相应文件。当前可复现命令以根 README 和 examples/README.md 为准。

The three Spine MCP projects were read-only research references, not runtime dependencies and not vendored here. Only the official Spine runtime is initialized as a submodule. Official sample analysis can be regenerated with `npx tsx scripts/research-examples.ts` after submodule initialization; its derived outputs remain local.
