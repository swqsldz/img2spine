# 新工作流实测：山地斥候

这次从新母图开始，用内置 imagegen 制作黑发短须、橙色夹克、灰色长裤的朝右半侧身男性角色，未复用旧角色贴图或像素关节坐标。产物包含待机、原地行走、原地跑步、徒手出拳四个动画，使用锁定的 Spine 4.3 runtime。

## 实际结果

- 12 个部件、19 根骨骼、2 张双骨骼加权的连续腿网格、4 个 IK 约束、1 张纹理页。
- 先编写 `asset-plan.json`，由 `prepare` 输出制作提示；根据新母图的卷袖更新肘部材质与遮盖设计。
- 保留右侧近手的手背、左侧远手的掌面，以及外侧带扣/内侧简洁的独立靴子；远臂在当前四动作中置于两腿后方。
- 膝部从第一次拆件就使用完整髋踝贴图；脚掌保持独立，走跑使用地面接触轨迹。
- 真正执行了入库、亮暗底复原、局部配准修订、编译、runtime 连续求值与两版共 96 帧浏览器采样；最终 48 帧逐动作复核。
- 最终验证无 reader/引用错误、网格翻折或循环首尾数值接缝；腿部接触点误差小于 0.001 像素。这是骨骼目标误差，不等同于贴图鞋底的所有像素完全静止。

## 首轮失败与返工

| 阶段         | 发现                                         | 处理                                                       |
| ------------ | -------------------------------------------- | ---------------------------------------------------------- |
| 首张拆件图   | 远侧裤腿出现第二段连体腿；头部重复衣领       | 第一次局部重绘，仅选取修正后的头和远腿，其余十部件仍用首图 |
| 首次复原     | 头偏低，衣领遮住胡须；近肩插接偏移           | 头上移 28px，按新图调整近肩锚点；保存第二版测量数据        |
| 首次动作复核 | 出拳时露出躯干贴图的空心圆形袖孔             | 第二次局部重绘，仅替换躯干的隐藏肩部材质；不降低出拳幅度   |
| 最终复核     | 四动作范围内关节保持连接，袖孔不再呈暗色空洞 | 保存资源哈希、48 帧证据和视觉复核记录                      |

共 **4 次内置 imagegen 调用**：母图一次、拆件一次、局部修正两次；另有一次配准修订。首次动作的数值检查即通过。最终候选沿用相同动作数据，未通过减小动作来掩盖缺陷。该样本证明流程能定位并修复问题，**不能称为首次生图即交付成功，也不能据此估算普遍成功率**。

此次新增的具体经验是：部件数量正确不能证明单个部件没有多余肢体；“完整隐藏区域”还应明确禁止绘制空心袖孔；初始姿势之外，必须在抬臂和出拳后检查肩部。刚性袖片的轮廓和服装褶皱仍有剪纸动画感，复杂扭身、俯仰、深蹲不在这次验收范围内。

## 文件与复现

- 原图、各轮提示、制作计划与测量：`output/mountain-scout/source/`。
- 首次复原：`candidate-01/assembly/`；带袖孔问题的动作候选：`candidate-02/`。
- 最终资源与帧：`output/mountain-scout/candidate-03/`。
- 提取真实 alpha：`node scripts/chroma-key.ts <magenta.png> <rgba.png>`。该工具仅适用于主体不含品红的明确去色路线，保存原图和处理报告。

```powershell
npm run demo:scout
npm run qa -- output/mountain-scout/candidate-03
npm run spine -- preview output/mountain-scout/candidate-03 --port 4182
```

重建不会再调用生图服务。修改资源后必须重新查看 runtime 帧，不能复用旧的视觉批准。未使用 Spine 编辑器，也未声称通过 Unity 或真机验证。
